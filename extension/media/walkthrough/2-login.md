## Log in once

**Log in** opens Claude Code in a terminal. Type `/login` and follow the link in your browser.

You only do this **once per machine**. Every Steerhouse chat and terminal reuses that login.

Why did a terminal ask me to log in even though the Claude app is logged in? The desktop app keeps its own login. The Claude Code CLI keeps a separate one in `~/.claude`, and that's the one Steerhouse uses.
