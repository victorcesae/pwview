## Claude Code is the engine

Steerhouse doesn't call any model itself. It drives **your own Claude Code**, so whatever Claude Code is set up with just works: your Claude subscription, an API key, Amazon Bedrock, Google Vertex or a gateway.

- Click **Check setup** to see what's already in place.
- No Claude Code yet? **Install Claude Code** opens a terminal with the official installer typed in. Press Enter to run it.

> Using Remote-SSH? Do every step **in the SSH window**. Everything installs and runs on the remote machine.
